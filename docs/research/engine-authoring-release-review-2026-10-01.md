## Actual Host authority

`NativeWebHost::authoring_snapshot()` exports the same HostCatalog and
PluginRootSnapshot used by the existing resolver, without starting factories
or opening listeners. `load_plugin_root_snapshot()` uses the official Engine
reader, locking and validation. Relay runtime and the exporter share one
`composition()` registration function. Runtime compares persisted catalogue
with compiled authority before admitting the filesystem Root.

Relay authoring sources now live under `plugin-sources/`; `plugins/` is reserved
for actual Root instances. Packaging exports genuine compiled Host authority,
preserves Root configuration, validates source and packaged Roots and records
integrity hashes. It never infers authority from source scanning.

A custom Host with an explicit `lenso.contracts.json` uses the official
Contracts discovery and read-only Check processor when no App freshness receipt
exists. Existing App receipts retain priority. No App receipt is fabricated.

source Plugins, reports no diagnostics and passes project check. Runtime remains
`not_observed`; facts does not pretend an HTTP runtime was observed. Final probe
