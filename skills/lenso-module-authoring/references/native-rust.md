# Native Rust Module recipe

Use this branch for a Module compiled into the App binary as an ordinary Cargo
dependency. App Composition still decides whether the linked package becomes a
Module Instance. The ordinary authoring path uses the public `lenso` facade;
direct Adapter factories are an implementation-level compatibility escape
hatch, not starter code.

## 1. Find the live API

Read the selected versions in `Cargo.toml` and `Cargo.lock`, then inspect these
symbols in the installed dependency source:

- `lenso::prelude::{module, provides, ModuleConfig, Port, Lifecycle, Ctx}`;
- the generated Capability type, Client, request/response, and Domain Error;
  and
- `NativeModuleRegistry::with_linked_factories` at the product Runner boundary.

The current reference implementations are `lenso-secrets-env-module` in
`LioRael/lenso-secrets-module`, `lenso-otel-module` in
`LioRael/lenso-otel-module`, and the Web Ingress/Egress Modules in
`LioRael/lenso-web`. Treat those repositories and the selected crate versions
as the source of truth when this example differs.

## 2. Create the package

A small provider-only package normally needs:

```text
crates/greeting-module/
├── Cargo.toml
├── src/lib.rs
└── tests/module.rs
```

Depend on `lenso`, the Capability contract crate, and only the libraries the
Module itself owns. The App binary depends on the Module crate and discovers
its generated linked factory.

## 3. Implement behavior through the facade

This is the minimum request-provider shape. `greeting_contract` represents a
contract crate generated by `lenso-contract-codegen`.

```rust,ignore
use greeting_contract as greeting;
use lenso::prelude::*;

#[derive(Clone, Debug, serde::Deserialize)]
#[serde(deny_unknown_fields)]
struct GreetingConfig {
    prefix: String,
}

#[module]
#[derive(Clone, Debug)]
struct Greeter {
    #[config]
    config: GreetingConfig,
}

#[provides(greeting::Greeting)]
impl Greeter {
    async fn greet(
        &self,
        _context: Ctx,
        request: greeting::GreetRequest,
    ) -> Result<greeting::GreetResponse, greeting::GreetError> {
        if request.name.trim().is_empty() {
            Err(greeting::GreetError::EmptyName)
        } else {
            Ok(greeting::GreetResponse {
                message: format!("{} {}", self.config.prefix, request.name),
            })
        }
    }
}
```

The facade derives package identity from `[package.metadata.lenso].package-id`
and Cargo version, decodes configuration, derives the Descriptor, aggregates
Request/Stream/Event endpoints, constructs one factory, and registers it in the
linked catalog. Stateless Modules omit the `#[config]` field entirely.

## 4. Add lifecycle and dependencies only when needed

Endpoint-only Modules need no lifecycle declaration. A Module with resources
or managed work opts in and overrides only the phases it owns:

```rust,ignore
#[module(lifecycle)]
#[derive(Clone, Debug)]
struct Worker { /* config and Ports */ }

impl Lifecycle for Worker {
    async fn prepare(&self, context: PrepareContext) -> Result<(), RuntimeFailure> {
        // Parse/check configuration and reserve reversible resources here.
        Ok(())
    }

    async fn activate(&self, context: ActivateContext) -> Result<(), RuntimeFailure> {
        // Build generated clients from context.dependencies(), then register
        // work through context.tasks().spawn_local(...). Pass
        // context.readiness() to ingress/background work that must wait.
        Ok(())
    }

    async fn deactivate(&self, context: DeactivateContext) -> Result<(), RuntimeFailure> {
        // Close Module-owned resources; Kernel cancels and joins managed tasks.
        Ok(())
    }
}
```

Declare generated consumers as `Port<Client>` fields. Generated lifecycle glue
connects them from the Plan-owned `ModuleDependencies` before activation; there
is no global Capability registry.

## 5. Register and compose

The Runner makes the linked factory available:

```rust,ignore
let native = NativeModuleRegistry::new().with_linked_factories();
let adapters = ExecutionAdapterCatalog::single(native);
```

Static registration is only availability. App Composition must still select a
Module Instance whose package identity/revision matches the factory and must
declare every endpoint, requirement, and binding. Continue with
`lenso-app-composition` for that project edit.

## Completion

This branch is complete when a fresh factory generation parses configuration,
exposes the exact selected endpoints, obtains dependencies only from lifecycle
context, cleans up managed work, and passes one real Plan-driven invocation.
